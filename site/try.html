Try it live · exit_liquidity

Could you sell it, and what would it cost?

Pick a token and how much you hold. Hanko asks three live sources right now (RYO's market data, every trading pool on DexScreener, and a real sell quote from Jupiter) and tells you in plain words whether you could get out, and what it would cost you.

For builders: it runs RYO's analyze_token, DexScreener depth and an executable Jupiter quote through the same pure assess() the CLI uses. When a quote exists the answer rests on it, and the model's own figure is shown beside it, error and all. If a source is down, the answer says which one and comes back from the others, in RYO's own public envelope.

The full receipt
EXIT_LIQUIDITY · LIVE CHECK LIVE OUTPUT 
Pick a token and a size, then run a live check. Usually 2 to 8 seconds: three real network calls.

Every figure above is computed from what this call actually returned. Solana tokens get an executable quote; ETH and BTC are measured through their wrapped forms on Ethereum, where no keyless quote venue exists, so their cost is modelled and labelled as such. Also callable the way RYO's own tools are: POST /api/tools/exit_liquidity/call, or as an MCP server at /api/mcp. See the exit_liquidity docs.
